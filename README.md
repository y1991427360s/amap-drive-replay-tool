# 自驾轨迹回放工具

一个原生 HTML + CSS + JavaScript 实现的高德地图自驾轨迹回放页面。页面内可直接填写高德 Key 和途经点，程序会自动把相邻途经点拼接成完整自驾轨迹。

## 本地运行

在项目根目录执行：

```bash
python -m http.server 8080
```

浏览器打开：

```text
http://localhost:8080
```

## 页面内填写

打开页面后，在左上角面板里填写：

- JS API Key：用于加载高德地图 JS API 2.0。
- Web Service Key：用于地理编码和驾车路径规划。
- 安全密钥：如果 JS API Key 开启了安全密钥校验则填写，没有则留空。

点击「保存配置」后会保存到当前浏览器的 `localStorage`。真实 Key 不会写入项目文件。

## 途经点输入

现在不需要重复输入上一段终点和下一段起点。只要按顺序填写途经点：

```text
点 1：青岛市五四广场
点 2：日照市万平口景区
点 3：临沂市沂蒙山银座天蒙旅游区
点 4：周口市
```

程序会自动生成：

```text
青岛市五四广场 -> 日照市万平口景区
日照市万平口景区 -> 临沂市沂蒙山银座天蒙旅游区
临沂市沂蒙山银座天蒙旅游区 -> 周口市
```

每个途经点支持两种输入：

- 地址：例如 `青岛市五四广场`
- 经纬度：一个输入框，格式为 `经度, 纬度`，例如 `120.3841, 36.0608`

可点击「新增途经点」添加更多点，也可以点击「读取示例」从 `data/segments.json` 读取默认路线并自动转换为途经点列表。

## segments.json

`data/segments.json` 仍然保留原始段落格式，方便作为示例数据：

```json
[
  {
    "start": "青岛市五四广场",
    "end": "日照市万平口景区"
  },
  {
    "start": "日照市万平口景区",
    "end": "临沂市沂蒙山银座天蒙旅游区"
  }
]
```

页面读取示例时会把它转换为：

```text
青岛市五四广场
日照市万平口景区
临沂市沂蒙山银座天蒙旅游区
```

## 申请高德 Key

1. 打开高德开放平台：https://lbs.amap.com/
2. 注册并登录账号。
3. 进入「应用管理」创建应用。
4. 在应用下创建 Web 端 JS API Key 和 Web Service Key。
5. 如果 JS API Key 开启安全密钥校验，把安全密钥填入页面。

## 播放

填写 Key 和至少 2 个途经点后点击「加载路线」。路线加载完成后，可使用开始播放、暂停、继续、重新播放和速度选择。

播放速度支持预设的 1x、2x、5x、10x、50x、70x，也支持选择「自定义」后输入任意倍速，例如 `50` 或 `70`。速度修改后重新播放生效。

页面会显示当前路段、总路段数、总距离和总耗时。

## 常见错误排查

### 地图加载失败

检查 JS API Key 是否正确，是否启用了 JS API 服务，域名白名单是否允许 `localhost`。如果启用了安全密钥校验，确认安全密钥已填写。

### USERKEY_PLAT_NOMATCH

这个错误表示 Key 平台类型不匹配。常见原因是把 JS API Key 填到了 Web Service Key 输入框。

请在高德开放平台创建或选择「Web服务」类型 Key，并填入页面的「Web Service Key」输入框。JS API Key 只填在「JS API Key」输入框。

### 地址解析失败

页面和控制台会提示具体失败的地址。可以把地址写得更完整，例如加上省、市、区，或者改用精确经纬度。

### 经纬度格式错误

经纬度必须填在一个框里，格式为 `经度, 纬度`，例如 `120.3841, 36.0608`。

### 某一段路线规划失败

页面和控制台会提示具体路段。程序会跳过失败路段并继续处理后续路段。

### fullPath 为空

说明所有路段都没有得到有效路径。检查 Key、服务权限、地址、经纬度和浏览器控制台错误。
